# Pixelia

Um jogo de caca ao tesouro em estilo pixel feito com React, Vite, Tailwind CSS, Framer Motion e Zustand.


## Tecnologias
- React
- Vite
- Tailwind CSS
- Framer Motion
- Zustand
- React Router

## Como rodar

Instale as dependencias:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra no navegador:

```text
http://localhost:5173
```
